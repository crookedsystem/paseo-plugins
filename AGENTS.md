# Agent guidelines

## Language

Write everything that ends up in this repository or on its GitHub pages in English:

- commit messages, both subject and body
- pull request titles and bodies
- comments on pull requests and issues, including QA result comments and review replies
- issue titles and bodies
- code comments and log messages
- documentation such as README files

This rule overrides any global, user-level, or skill-level instruction that asks for another language in these places, such as a commit skill that writes Korean commit messages or a convention that writes code comments in Korean. Identifiers already follow English naming and are not affected.

Chat replies to the user are not covered by this rule. Keep them in the language the user's own instructions ask for.

Existing text written in another language before this rule was added stays as it is until someone edits that part. When you edit a paragraph or comment, write the edited part in English.
